# Аналитическая система оценки качества сна и когнитивной продуктивности

Дипломная работа — интерактивное веб-приложение на Python (Streamlit) для разведочного анализа данных (EDA) о сне и факторах образа жизни, с моделью машинного обучения для прогноза класса когнитивной продуктивности.

## Возможности

- Загрузка и первичная обработка открытого датасета `Sleep_health_and_lifestyle_dataset.csv`.
- Хранение данных в SQLite (модуль `database.py`, транзакционная загрузка по трём таблицам через `load_csv_to_db()`).
- Разведочный анализ данных (EDA): описательные статистики, метрики, визуализация распределений и зависимостей.
- Модель машинного обучения (RandomForest) для предсказания класса когнитивной продуктивности.
- Кросс-валидация по 5 фолдам (CV accuracy = 0,935 ± 0,094).
- Ролевой интерфейс:
  - **Сотрудник** — форма из 11 полей, расчёт `sleep_index` и прогноз продуктивности через `predict_single()`.
  - **HR-менеджер** — вкладки «Общая аналитика» (KPI, таблица, графики), «Прогнозы» (таблица с фильтром и экспортом CSV), «Качество модели» (метрики, матрица ошибок, важность признаков).
- Кэширование через `@st.cache_resource` и `@st.cache_data`.

## Стек технологий

- Python, Streamlit — приложение и интерфейс
- Pandas — обработка и анализ данных
- SQLite — хранение данных
- RandomForest — классификатор (n_estimators=100, max_depth=10, min_samples_split=4, class_weight='balanced', random_state=42)
- Модель сохраняется в файл `sleep_model.joblib`

## Модель и метрики

- Стратифицированное разбиение выборки: 80% обучение (299 записей) / 20% тест (75 записей).
- Кросс-валидация по 5 фолдам: CV accuracy = 0,935 ± 0,094.
- Прогноз выполняется функцией `predict_single()`: принимает 11 признаков, возвращает класс продуктивности, текстовую метку и уверенность модели.
- Топ-4 признака по важности: `sleep_index` (43,2%), `sleep_duration` (19,4%), `sleep_quality` (13,0%), `stress_level` (9,8%).

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура ключевых модулей

- `app.py` — пользовательский интерфейс Streamlit, ролевая модель.
- `database.py` — инициализация БД SQLite, загрузка датасета, доступ к данным.
- модель сохраняется в `sleep_model.joblib`, прогнозы — в таблицу `predictions`.
